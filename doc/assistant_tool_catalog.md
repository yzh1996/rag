# 对话式经营分析助手工具说明

本文件由工具注册定义生成；工具检索索引写入现有RAG向量库。

## 按名称或ID查找达人账号

工具ID：resolve_anchor
工具名称：按名称或ID查找达人账号
所属领域：达人账号
用途：把用户提到的达人名称或账号ID解析成唯一anchor_id；支持名称搜索。重名时返回候选项，不能猜选。
适用关键词：主播、达人、账号、主播ID、anchor_id、账号名称
必填参数：anchor_name
参数说明：anchor_name：达人名称或账号ID，用户未提供时必须先追问
返回内容：候选账号ID、名称、主营类目和匹配状态
调用示例：查找陈洁KiKi对应的主播ID

## 分析达人直播表现

工具ID：analyze_anchor_live
工具名称：分析达人直播表现
所属领域：达人直播
用途：查询指定主播和日期范围内的直播销量、GMV、场次、活跃日、品类分布和头部商品。仅返回演示数据库的模拟数据。
适用关键词：主播、达人、直播、直播间、场次、直播销量、GMV
必填参数：anchor_id、start_date、end_date
参数说明：anchor_id：经账号查找工具确认的ID；start_date：含首日的YYYY-MM-DD；end_date：含末日的YYYY-MM-DD
返回内容：直播销量、GMV、场次、品类和商品统计，含时间范围及模拟数据标记
调用示例：查询A001近90天直播销量和场次

## 分析达人带货商品和品类

工具ID：analyze_anchor_products
工具名称：分析达人带货商品和品类
所属领域：达人商品选品
用途：汇总指定主播在日期范围内的直播和视频商品销量、销售额、品类占比及头部商品集中度，为选品分析提供事实数据。仅返回演示数据库的模拟数据。
适用关键词：主播、达人、商品、品类、类目、带货、选品、品牌、价格带
必填参数：anchor_id、start_date、end_date
参数说明：anchor_id：经账号查找工具确认的ID；start_date：含首日的YYYY-MM-DD；end_date：含末日的YYYY-MM-DD
返回内容：商品和品类销量、金额、占比、Top商品及集中度，含模拟数据标记
调用示例：分析A001近90天带货商品和品类结构

## 对比同类达人表现

工具ID：compare_anchor_category
工具名称：对比同类达人表现
所属领域：达人竞品对比
用途：将指定达人与演示库中相同主营类目的其他达人对比近90天销量和带货商品数量；返回样本量，样本过少时明确提示。仅使用模拟数据。
适用关键词：主播、达人、竞品、同类、对标、行业、比较、选品、类目
必填参数：anchor_id、start_date、end_date
参数说明：anchor_id：经账号查找工具确认的ID；start_date：含首日的YYYY-MM-DD；end_date：含末日的YYYY-MM-DD
返回内容：本人总销量、同类账号销量中位数、对照账号及样本量警告，含模拟数据标记
调用示例：比较A001近90天同类达人销量

## 检索选品与运营知识

工具ID：search_selection_knowledge
工具名称：检索选品与运营知识
所属领域：运营知识库
用途：按已确认的主营品类、渠道特点和用户目标，从当前用户可访问且已发布的内部知识中找选品方法、运营案例和规则，返回片段与出处。
适用关键词：选品、选品方向、运营、方法、案例、直播、视频、品类
必填参数：query
参数说明：query：完整描述需要查找的品类、渠道和经营问题
返回内容：相关知识片段、原文件名、页码和文档ID；无资料时返回空结果
调用示例：食品类目近90天直播选品建议与账号匹配方法
