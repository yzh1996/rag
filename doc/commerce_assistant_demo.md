# 对话式达人经营分析演示

> 本文描述保留的旧SQLite演示。当前本机MySQL使用字段字典中的原业务表，造数和直播复盘请阅读 [本机MySQL业务数据说明](mysql_business_data.md)，不要执行下方旧库初始化命令。

当前新增能力使用独立的本地模拟库，不写入 `rag_qa.db`，所有结果都会标记为模拟数据。

## 初始化模拟数据

```powershell
python scripts/seed_commerce_demo.py --end-date 2026-10-17
```

命令创建 `data/commerce_demo.sqlite3`，包含 6 个样例达人、12 个商品，以及近 90 天直播/视频日明细。脚本只在样例库为空时生成，不覆盖已有数据。

## 工具说明知识库

工具注册信息位于 `core/assistant_tool_catalog.py`，同一份定义会生成项目 RAG 向量索引中的工具说明。另有可上传的参考文件 `doc/assistant_tool_catalog.md`。通过现有知识库上传页面上传此文件时，把“文档分类”选为 `assistant_tools`；完成现有审核和知识版本发布后，工具发现也可以从已发布知识中检索说明。

检索结果只用于找候选工具；后端仍核对候选工具是否注册，并按固定参数和只读查询函数执行。普通知识检索会排除 `assistant_tools` 类别。

## 示例问题

- 分析陈洁KiKi近90天直播和视频表现，并给出接下来的选品方向。
- 分析主播 A003 近30天的直播表现。

报告会展示数据时间范围、分析步骤、商品与品类结果、同类模拟账号对比和知识来源。样例同类账号数量较少，不能代表行业整体；数据也不包含真实利润、退款、转化归因或外部行业趋势。
